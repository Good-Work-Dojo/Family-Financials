## What this list covers

- **The runtime dependencies**: the packages the dashboard is built from (npm) and the Python distributions the ETL
  image runs with. The table below is generated by `tools/verify/licences.py --write` from `app/package-lock.json`
  and from the runtime ETL image, and the gate (`tools/verify/ci.sh`) fails when it is out of date or when any of
  them is under a licence outside the project's allow-list.
- **The programs the images carry**: Caddy, supercronic and the Python interpreter, below.
- **The bank formats**: where each shipped preset's description of a file layout comes from.

Build-only tools (Node.js, npm and the dashboard's dev dependencies, uv, the test suites' packages) are used to build
and test the program and are not part of what it runs. The operating-system layers of the base images (Debian in the
ETL image, Alpine in Caddy's) are separate programs those images carry, each under its own licence, and are outside
this list.

### Notices that travel with the code

**Apache ECharts** (the dashboard's charts, Apache-2.0) asks that its NOTICE file be reproduced:

```text
Apache ECharts
Copyright 2017-2024 The Apache Software Foundation

This product includes software developed at
The Apache Software Foundation (https://www.apache.org/).
```

ECharts also embeds parts of d3.js, under the BSD 3-Clause licence (see `licenses/LICENSE-d3` in its package).

**certifi** (the CA bundle the bank-feed fetch trusts, MPL-2.0) is used unmodified. Its source is the installed
package itself (`/opt/venv/lib/python3.12/site-packages/certifi/` in the ETL image, the Python files and
`cacert.pem` as published) and its project, https://github.com/certifi/python-certifi, where every release's source
is available.

The **anthropic** and **openai** SDKs (Apache-2.0) are installed unmodified, with their licence and notice files in
their packages (anthropic's vendored `httpx_aiohttp` carries a `NOTICE.md` of its own).

Caddy and supercronic are written in Go, and each binary carries the Go standard library and the Go modules it was
built from. `THIRD_PARTY_LICENSES`, which both images carry, holds all of their licence texts (and NOTICE files where
a module has one), after the npm packages', at the versions each binary's own build information names; the gate fails
when a module compiled into either binary has no text there (`tools/verify/licences.py`, which keeps them in
`deploy/licences/go/`).

## Bank formats

Each shipped preset (`etl/importers/presets/*.yaml`) describes the layout of one bank's download: which columns hold
the date, the amount and the description, the date format, the sign. Those are facts about a file. Each preset's
`source:` names where they were read, and every one was written in this project's own words: no code, text or test
data from those projects was copied.

| Preset | Facts read from | Its licence |
|---|---|---|
| `bofa_card` | bank2actual (`bank2actual.py`) and bank2ynab (`bank2ynab.conf`) | MIT, MIT |
| `capital_one_card` | csv2ofx (its Capital One mapping and test file) | MIT |
| `discover_card` | beancount_reds_importers (its Discover importer) | GPL-3.0 |
| `schwab_checking` | csv2ofx (its Schwab checking mapping and test file) | MIT |
| `wells_fargo` | the beancount.io Wells Fargo converter page; the README of au5ton/expense-report; the Firefly III import configuration for Wells Fargo | none stated, none stated, CC BY-SA 4.0 |

The links and the dates they were read are in each preset's `source:`.
